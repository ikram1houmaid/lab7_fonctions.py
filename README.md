# Lab 7 : Les fonctions en Python

## Objectif
Apprendre à créer et utiliser des fonctions en Python, comprendre les paramètres, les valeurs de retour et la portée des variables.

## Contenu du laboratoire

### Étape 1 : Créer une fonction
- Utilisation de `def`.
- Appel d'une fonction.
- Exécution de plusieurs instructions.

### Étape 2 : Les paramètres
- Passage d'informations à une fonction.
- Utilisation des paramètres.
- Création de la fonction `presentation(nom, age)`.

### Étape 3 : L'instruction return
- Retourner un résultat.
- Stocker une valeur retournée.
- Différence entre `print()` et `return`.

### Étape 4 : Les paramètres optionnels
- Définir des valeurs par défaut.
- Utiliser les arguments nommés.
- Création de `afficher_message()`.

### Étape 5 : Les arguments variables (*args)
- Accepter plusieurs arguments.
- Calculer une somme.
- Calculer un produit.

### Étape 6 : Variables locales et globales
- Comprendre la portée des variables.
- Utiliser le mot-clé `global`.
- Privilégier `return` pour modifier les valeurs.

### Étape 7 : Mini-projet de gestion des notes
Création de plusieurs fonctions :
- `moyenne(notes)` : calcule la moyenne.
- `appliquer_bonus(notes, bonus)` : ajoute un bonus.
- `filtrer_notes(notes, seuil)` : filtre les notes.
- `rapport(notes)` : génère un rapport complet.

### Étape 8 : Exercices supplémentaires
- `min_max(notes)` : retourne la note minimale et maximale.
- `normaliser(notes, sur)` : normalise les notes.
- Sauvegarde du rapport dans un fichier texte.

## Technologies utilisées
- Python 3
- Visual Studio Code

## Exécution du programme

Ouvrir le terminal dans le dossier du projet et exécuter :

```bash
python lab7_fonctions.py
```

## Résultat attendu
Le programme affiche les résultats des fonctions, calcule les moyennes, applique les bonus, filtre les notes et génère un rapport sauvegardé dans `rapport_notes.txt`.
